# Guess The Word 🎯

A simple interactive word guessing game built with **JavaScript**, **HTML**, and **CSS**. The game selects a random word and the player has limited attempts to guess it based on typed letter input and visual feedback.

### 🌐 Live Demo  
https://alan23bh.github.io/guess-the-word/

### 🧠 Features
- Random word selection
- Letter input validation
- Win/Lose feedback messages
- Replay/reset functionality
- Clean and simple UI design

### 🛠 Tech Used
- JavaScript (DOM manipulation + game logic)
- HTML5 & CSS3
- GitHub Pages for deployment
